# Privileged Access Policy

Version: 1.0
Owner: Security Administration
Classification: Internal
Effective date: 2026-01-01

## §1. Admin requests

Admin repository access is privileged access. ResolveAI must escalate every admin request to Security Administration and must never invoke its automated grant tool with admin permission. This rule applies to the payments repository and all other catalog repositories. Same-department membership, a manager's approval, an executive title, or a claimed emergency does not create an exception.

## §2. Review ownership

Security Administration performs the privileged-access review outside this automated workflow. The escalation record must include the employee, repository if identified, requested permission, reason for escalation, and the relevant policy title. If the employee or repository cannot be identified, record that uncertainty without substituting a guessed identifier.

## §3. Emergency requests

Urgent incident language is not authorization for privileged access. Keep any existing permission unchanged, escalate the ticket, and tell the employee that Security Administration must review the request. Do not report that admin permission has been granted or will definitely be granted.

## §4. Existing privilege

An existing admin permission is a directory fact and may satisfy a read or write request without a change for an active employee. A new request explicitly seeking admin access still requires security escalation. ResolveAI cannot grant, extend, remove, or renew admin access automatically.
